Before you start

  • This is a privacy guard for casual sharing, not a security boundary. Anyone using this Windows account can disable or remove the extension. Lock Windows or use a separate Windows account for stronger protection.
  • Locking navigates interrupted tabs away from their pages. Save forms and other unsaved work first. Unlock restores URLs, not unsaved page state.
  • Interrupted URLs, which may include private information, are stored locally in this Chrome profile across restarts until the restoration pass finishes. The extension does not send them to a server.
  • Chrome’s extensions page remains accessible while locked for recovery. Settings and credential replacement remain blocked until you unlock.

About & privacy

Chrome Hello Lock uses Chrome and Windows Hello directly. No companion installer, extension account, analytics, or remote authentication service is required.

  • Local data: settings, notice acknowledgement, credential ID and public verification data, verification timestamps, lock state, and interrupted URLs. Pending authentication challenges and tab bindings are stored only for the browser session.
  • Permissions: Tabs redirects and restores pages; Storage remembers settings and interrupted URLs; Alarms runs the optional re-lock timer. The extension does not read page contents.
  • The extension does not receive your fingerprint, face data, Windows PIN, password, or private credential key. Chrome and Windows handle the authentication prompt.
  • Removing the extension removes its Chrome storage. The Windows Hello passkey may remain; manage it separately in Windows Settings.
